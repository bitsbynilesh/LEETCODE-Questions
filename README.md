## 🔄 Workflow and Learning

A systematic, deliberate approach to mastering algorithmic patterns:

```text
  ┌─────────────────┐       ┌──────────────────────┐       ┌──────────────────────┐
  │ 1. Read & Trace │ ────► │ 2. Dry-Run Examples  │ ────► │ 3. Brute Force Code  │
  └─────────────────┘       └──────────────────────┘       └──────────────────────┘
                                                                       │
                                                                       ▼
  ┌─────────────────┐       ┌──────────────────────┐       ┌──────────────────────┐
  │ 6. Sync via Git │ ◄──── │ 5. Review & Note     │ ◄──── │ 4. Optimize Time/Mem │
  └─────────────────┘       └──────────────────────┘       └──────────────────────┘
```

1. **Understand & Clarify**: Identify problem constraints, edge cases, and bounds before writing code.
2. **Dry-Run by Hand**: Trace small sample cases with pen and paper.
3. **Establish Baseline**: Write a working brute-force solution to verify correctness.
4. **Optimize Complexity**: Analyze bottlenecks and apply appropriate patterns (Prefix Sum, Two Pointers, Binary Search).
5. **Note Patterns**: Save observations, edge-case pitfalls, and timing in LeetCode Notes.
6. **Automatic Sync**: Sync accepted code to GitHub via LeetSync for review.
